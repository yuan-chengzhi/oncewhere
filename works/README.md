# 作品记录

当前已有[《月背拾遗司》第一夜的可玩初版](moon-office/README.md)，处于首轮制作与打磨阶段，尚无真实观众反馈。技术库中的其他地图、信件、票据和空间配方仍是设计示例。

为作品创建独立目录，记录来源、工作焦点和使用范围；源自真实经历的作品可从[作品简报模板](../templates/work-brief.md)开始。只有实际产生分镜、实现或反馈后，才加入相应材料。幻想故事的改编与真实人物经历分开标注。

```text
works/
  <work-slug>/
    brief.md       为什么为这个人做这件作品
    storyboard.md  关键片段与动作的意义（形成方案后）
    review.md      实际体验与复盘（发生体验后）
```

使用素材代号关联原始材料。私人访谈、照片、录音及完整授权记录保存在根目录 `private/` 或独立存储中；适合仓库协作的摘要注明来源与使用范围。示例素材与真实素材清楚区分。

实现形式确定后再决定代码和运行资产的位置。每件作品单独记录如何打开、如何交付和如何保留，不预先搭建通用引擎。
