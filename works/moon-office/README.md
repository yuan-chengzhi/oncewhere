# 月背拾遗司 · 第一夜

一件关于迟到、照料与安放的互动小剧场。与小狐狸、小狗一起，翻看一枚月牙胸针，拼起车票，等一句话抵达，修好最小的扣件，再把月亮收进第七号柜。

**状态：可完整体验的第一轮制作版，继续打磨中。** 它有五章、独立物件机关、原创钢琴音序与五种音效、自动续玩、章节回看和记录下载。HTML版角色主要通过场景插画与文字表演；原生样段另行验证了分层纸偶动作。没有宣称已通过真实观众体验或音乐听感验收。

后续已完成[成熟作品对照与前沿技术研究](reviews/README.md)，并做出可打开的三维胸针和单图空间实验。下一版的媒介与技术基础重新开放，允许原生桌面程序、互动影片或配好环境的装置；HTML是这一版的交付方式，不是长期约束。

制作样段已另行落地为[原生桌面“修理与递灯”样段](native/README.md)：Godot Compatibility 场景把分层狐狸/小狗、同一枚可连续翻面的三维胸针、扣件受阻与合拢、递灯动作和自适应声音放在一场戏里。Linux、Windows x86_64 与 macOS Universal 未签名包位于 `native/dist/`（构建产物不提交到源码库）；这段用于确定下一版的表演标准，不替代本版 HTML。

## 打开作品

构建后，直接用浏览器打开 [`dist/moon-office.html`](dist/moon-office.html)。这是约 8.7 MiB 的独立收藏版，包含画面、字体、音乐与音效，不需运行服务器。文件名和目录可以改变；浏览器对本地文件的进度存储方式可能不同，下载的值班记录可另外保管。

开发预览：

```bash
cd ~/oncewhere/works/moon-office
npm ci
npm run dev
```

打开 <http://localhost:4173>。进入作品后才启动声音；右上角可以静音和调整音乐音量。每个机关都可以用点击或键盘完成，也可以请求提示或请值班员帮忙，不改变结尾。

构建与浏览器检查：

```bash
npm run build
npx playwright install --with-deps chromium
npm test
```

构建生成两种交付：`dist/index.html` 与相邻资源组成普通静态网站；`dist/moon-office.html` 是单文件收藏版。两者由同一应用生成。`dist/` 是构建产物，不提交进源码库；首次使用须构建。本轮环境使用 Node 24，Vite 8.3、TypeScript 7.0.2；依赖版本由 lockfile 固定。已有浏览器的环境可通过 `PLAYWRIGHT_CHROMIUM_PATH` 指定测试执行文件。

结束后“留一份在身边”下载的是**静态值班记录**，保存文字和月牙图样。它与包含完整音乐、交互和场景的收藏版是两种不同文件。

## 本版包含什么

| 片段 | 可亲手完成的事 |
|---|---|
| 第七号柜 | 翻过胸针，看清双孔与方形缺口；读到来自未来的标签 |
| 候车室 | 点击两张车票交换位置，让两条线在接缝与边框处都连续 |
| 回声星球 | 送出“我在这里”，看它绕过山谷，再让“我知道”返回 |
| 月背首饰街 | 比较孔距与缺口；一枚旧银扣恰好合适 |
| 归途与安放 | 逐盏留下三盏灯，把胸针放回软布，贴好标签；时光鸟加入尾声 |

已到过的片段可从值班簿直接回看图文。完成后的抽屉可以再次打开。存档仅在当前浏览器，没有账号、遥测或后台服务；清理浏览器数据会移除自动进度。

## 为什么采用这个制作基础

固定镜头把制作预算集中到插画、物件细节、声音和节奏。Vite + TypeScript 负责开发与构建；DOM/CSS/SVG 承接布局、对白与机关，单 Canvas 只绘制少量光尘；Web Audio 解码钢琴与音效并控制循环、淡入和暂停。

本轮无需额外游戏引擎。它的精美程度取决于资产和表演，不由引擎名称保证。后续若出现大量角色动画或复杂空间操作，再根据实际需求评估。

图片、正文、可互动几何分别保留：场景可以重画，中文仍可编辑；票据端点、扣件形状和反馈仍由确定的数据控制。网页与收藏版均不调用在线生成服务。完整制作判断、已发现的问题与下一轮重点见[迭代记录](review.md)。
