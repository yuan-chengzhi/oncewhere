# 月背拾遗司 · 原生微缩剧场样段

这是“修理与递灯”制作样段的可运行版本。狐狸和值班小狗守在柜台两侧；同一枚月牙胸针在镜头前连续翻到背面，针会绕铰链打开，扣件会在接触时受阻，正确合拢只发出一次声音，随后灯在两双手之间移动。

解压后直接运行对应平台的程序，不需要 Godot、Python、Blender、模型工具或联网。Linux 与 Windows 包是未签名的 x86_64 便携包；macOS 是同时包含 arm64 与 x86_64 的未签名 `.app`。

macOS 用户双击 `moon-office.app` 即可打开；首次运行未签名应用时，系统可能需要在“系统设置 → 隐私与安全性”中允许打开。

## 操作

- `R`：翻转胸针并打开/收回针
- `1` / `2` / `3`：选择宽方、窄圆、窄方扣件
- `Space`：尝试扣合；前两种会在接触处停住，第三种在针打开后合拢
- `L`：让灯从狐狸一侧递到小狗一侧
- `M`：静音/恢复自适应音乐与材料声音
- 鼠标在胸针附近拖动：从小幅角度观察物件
- `Esc`：退出

这是制作标准样段，不是完整章节。动作、物件、声音和桌面交付会以这一段的实测结果决定后续扩展。
