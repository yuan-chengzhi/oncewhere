# 第一轮制作与迭代记录

日期：2026-09-21。状态：完整可玩初版，尚未最终定稿。

后续评审：[成熟作品对照与技术路线](reviews/README.md)对本轮的美术、表演和技术基础做了独立复查；包含六份报告与两个实际技术实验。本文保留为首轮制作记录。

本轮由主代理整合美术、界面与交互，三个子代理分别参与技术基础评审与浏览器验证、叙事与物件绘制、音乐制作。下文记录实际工作与观察，不包含真实观众反馈。

## 本轮完成的作品

五章首案与归途已经连通：翻看月牙、拼起车票、等待回声、辨认扣件、留灯回去、安放、合柜与时光鸟尾声。每关有提示和代为完成入口，结尾一致；可选小物件保留两个人的玩笑。

采用五幅场景插画（含独立尾声画面）、精确绘制的 SVG 物件、本地中文字体、92 秒钢琴主题与五个音效。角色身份、服装和主要材料尽量保持连续；音乐使用真实钢琴采样，保留旋律、乐句变化与循环尾响。制作方法和来源见[美术记录](art-notes.md)、[音乐记录](audio-notes.md)。

默认单人体验，使用点击或键盘；减少动态效果时关闭光尘与漂移，回声仍可完成。浏览器保存当前进度、已完成章节和音乐设置。完成后的抽屉可再次打开，已走过的片段可以直接回看图文。

交付同时包含静态网站与 **`dist/moon-office.html` 独立收藏版**。收藏版约 8.66 MiB，内嵌图片、字体和声音；结尾还可以导出单独的静态值班记录。它们都从当前代码产生，原始素材、乐谱与许可另外保留。

## 本轮发现并修正的细节

| 发现 | 已做的修正 |
|---|---|
| 票据的外框短线与票背采用不同缩放，正确排列仍会错位 | 统一坐标、缩放与顶部对齐；桌面与手机八对线头的屏幕纵坐标差均为 0px |
| 鼠标悬停会抬起票据，破坏“线已经接上”的视觉依据 | 悬停仅强调边缘；选中时才抬起 |
| 票号 01／02／03 直接透露次序 | 改成无序票号，保留两条线作为解谜依据 |
| 重新打开已拼好的票据时，状态文案仍说另一道没接上 | 从当前排列重新计算反馈 |
| 点击第三盏灯会连带点亮前两盏 | 每次只点亮下一盏；另保留明确的“一起点亮”入口 |
| 音量重新打开设置后显示默认值 | 实际增益、界面值与存档同步；旧存档有合理默认值 |
| 固定像素的回声路径在不同屏幕上位置不一致 | 使用同一 SVG 坐标中的路径与光点，随画幅缩放；离开页面时暂停路径与计时 |
| 手机横屏仍使用过高舞台 | 横屏单独压缩标题、对白与物件近景；390px 高度下主要操作在视口内 |
| 尾声的小星星、回程灯、空鸟笼未体现在画面中 | 补充保留状态的图层和专门的尾声画面；生成多出的一盏灯经图像编辑去除 |
| 素材和原始母带会增大发布包 | 将制作原稿归档到 assets；public 只保留实际播放资源 |

## 验证结果

最终运行 `npm run build` 成功；`npm test` **13 项全部通过**，约 1.3 分钟。浏览器为本环境的 Chromium，不以此推断所有浏览器已兼容。测试源见 [night.spec.ts](tests/night.spec.ts)。

| 范围 | 实际检查 |
|---|---|
| 桌面 1440×900、手机 390×844、横屏 844×390 | 三种尺寸均从头完成五章；自然等待和快进均经过，无控制台异常或资源失败 |
| 机关与恢复 | 错误票据、取消选择、交换后刷新续玩、两种错误扣件、逐盏点灯及重复点击、安放和合柜 |
| 留存 | 结尾刷新、已完成章节回看、抽屉重开、静态记录下载、损坏存档恢复 |
| 操作与动态效果 | 键盘独立完成开场物件，原生对话框约束焦点；减少动画时回声仍能抵达 |
| 音乐 | 实际 Web Audio 解码、循环源启动与物件音效；静音后的增益、刷新后恢复与音量回显 |
| 独立收藏版 | `file://` 打开，同时断网并拦截 HTTP/HTTPS；首关真实操作、完整结尾、音频和下载成功，网络尝试为 0 |
| 视觉复查 | 人工查看浏览器截图：桌面、390px、320px、横屏；未见关键控件遮挡或横向溢出；部分横屏物件弹窗的可选提示区仍需少量内部滚动 |

这轮还检查了音频解码、响度、削波和循环边界。技术结果与边界写在[音乐记录](audio-notes.md)。没有主观试听能力，因此没有把信号检测或自动播放通过写成“音乐已经很好听”的证据。

## 仍值得继续打磨的地方

1. **角色表演。** 当前主要是插画、对白和道具变化。小动作、目光、翻簿、托住扣件与合柜的连续表演，会显著影响作品感；应从一小段认真制作，而非给整幅背景漂移动画。
2. **动作的连续性。** 胸针已有前后状态与修复结果，开柜、翻面、装配之间仍可做更细的过渡。当前是可玩稿的实际边界。
3. **音乐听感。** 在耳机、手机扬声器和普通笔记本上试听，检查旋律、频段、循环是否疲劳，再调整演奏、音效比例与章节留白。当前没有声称获得这些反馈。
4. **真实节奏。** 自动化点击速度不能代表观众阅读速度。需要观察是否愿意摸索、哪段对白过密、是否自然想留下抽屉；尚不标称游玩时长。
5. **设备与内容。** 真正的 iOS Safari、Android 浏览器尚待验证；若之后确认私人原型，再针对人物、饰品和专属细节进行改编。

下一轮最有价值的投入是角色和物件的表演，以及实际试听后的声音调整。第一轮已留下可以独立体验和保存的完整结果，无需先扩充案件数量。
