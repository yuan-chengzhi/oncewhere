# 《月背拾遗司》交互与动画对照评审

日期：2026-09-21。范围：当前浏览器版本的完整第一夜；交互、动作、镜头与角色反应。本文是导演判断，不是观众反馈。

**结论：它已有统一而悦目的插画包装，也有完整可达的故事流程；距离精美交互作品最远的，是“我动了它，所以这个世界发生了什么”这一段。当前主体仍是背景插画 → 指示热点 → 物件弹窗 → 状态替换 → 完成文案。最值得投入的不是继续增加章节，而是让一枚胸针从桌面到手中、从缺件到合拢，全程保持为同一个物体。**

## 证据与体验边界

已读仓库 AGENTS、README、原始思考备忘录、project-core、product-map、creative-approach、作品 brief/review，以及 `src/main.ts`、`style.css`；关键图形另查 `objects.ts` 与 `story.ts`。

使用 Playwright 实际操作 `http://127.0.0.1:4173`，1440×900，独立新浏览器上下文，Chromium `/home/ubuntu/.cache/ms-playwright/chromium-1234/chrome-linux64/chrome`。没有注入存档，也没有调用应用内部完成函数。由可见按钮从封面走到终局：

1. 读完开场，打开一个可选细节，再进入胸针近景；正反翻看三次。
2. 点选并交换车票，观察选择、错误排列、接缝与完成状态，正常解开。
3. 两次回声均自然等待；第一次从点击到重新可发言的记录约 4.85 秒，包含脚本和截图开销。源码的每段旅行时间均为 4.2 秒。
4. 依次尝试宽孔扣、圆口扣与正确旧银扣，观察三种反馈。
5. 逐盏点亮三盏灯，回柜、安放、贴标签、经过时光鸟尾声，再打开收藏抽屉。

保存了 25 张过程截图和操作文本日志，位于本机 `/tmp/moon-interaction-review/`；用 `view_image` 查看了场景热点、胸针正背面、车票、回声中途、扣件选择与修复完成截图。临时证据不作为仓库长期资产。本次未重跑工程测试，未做真实手机验证，未主观试听音乐，不把无控制台异常写成审美通过。

成熟参照没有在本轮购买或亲自游玩。核实了作者/发行方资料，并从三部作品官方 Steam 商店提供的视频流下载无声画面，抽取连续帧查看：Assemble with Care《Gameplay Preview》约 12–21 秒，Gorogoa《Launch Trailer》约 40–52 秒，Samorost 3《Release Date Trailer》约 55–64 秒。时间为采样区间，预告有剪辑；不由此推断完整操作手感、实际输入延迟或声音听感。

## 当前动作究竟有多少内容

| 环节 | 实际存在的内容 | 断点与影响 |
|---|---|---|
| 场景到近景 | 漂亮的角色、桌面、灯光；主要热点和“近一点看”按钮 | 主要热点按同一 CSS 规则放在舞台中部；首章的星号在桌沿附近，不能识别为画中一枚胸针。点击后纸色对话框出现，画中物体没有被取起或放大。视线从场景转为阅读面板 |
| 翻胸针 | 可反复查看前后图；背面有确切孔距与缺口线索 | `flip` 切换布尔值后重写整个弹窗 SVG。没有侧边经过、重心移动、接触阴影变化；悬停的轻微旋转与翻面动作无因果关系 |
| 车票 | 三片、两道连续线、可视接缝；这是实际的视觉排列谜题 | 点击两片后位置直接替换；拼成的长椅图没有变成可进入/可观察的新场景。“拾起扶手旁的银光”由按钮文字宣告，画里的银光没有被发现和拿走 |
| 回声 | 双向光点沿同一山谷弧线旅行，顺序明确，可自然等候或快进 | 两次预置 4.2 秒，没有空间判断、输入节奏或等待中变化的角色状态。它是叙事节拍，不是推理谜题；可以成立，但需要让这几秒有可看的关系变化 |
| 修扣件 | 宽孔、圆口、正确件，判据清楚，错误有解释 | 本质是三选一匹配。选对立即换成修好胸针的正面与文案；孔从未靠近孔，扣件未进入扣座，针未合上。画面写“小狗托住胸针，小狐狸轻轻合拢扣件”，实际没有托住或合拢的表演 |
| 修复外观 | 修好状态会显示透亮玻璃石、金色裂纹 | 改了扣件同时也改了正面材质。回声石与这些变化存在故事联系，但没有把石头嵌入等可见动作；观众只能接受结果，无法从动作看懂哪些部位被修复 |
| 归途与收存 | 三盏灯逐盏亮起；抽屉保留胸针、纸和石头；尾声保留星星和灯 | 有状态留存价值。灯仍是弹窗中的节点，抽屉安放主要是图标出现；人物没有跟随点灯、腾位置或确认彼此都够得到的动作 |
| 可选发现 | 多个细节入口和两人的短对白 | 入口集中成文字链接，打开后是统一月亮图标与对白。主要奖励是“多读到一句”，不是从空间里发现物体的隐藏行为 |

证据定位：`main.ts` 的 `render()`、`showObject()`、`renderObject()`、`swapTicket()`、`sendEcho()` 以及 `clasp` 点击分支；`style.css` 的 `.hotspot`、`.brooch-touch`、`.repair-complete`；`objects.ts` 的 `broochSvg(back, repaired)`。

这不是说简单匹配或点击不配成为作品。问题是：操作现在改变的常常是说明与状态，而物体和人物没有完整地承担这些变化。把文字隐藏后，翻面尚能看出“背面不同”，修扣件却几乎只剩“选一张图，换成另一张图”。

## 三个具体对照

### 1. Assemble with Care：修复首先是一段物件行为

**核实事实。** 官方将修复有情感价值的旧物作为核心。Gameplay Preview 的磁带/播放器段落中，可见松散磁带、插入卷盘的铅笔、转到背面的机身、进入电池仓的电池、覆盖回去的盖板及螺丝刀。桌上的其他零件和工具继续留在原处，操作对象的朝向与遮挡发生变化。作者技术文章也明确说，游戏采用固定镜头，却仍要让画面有材质、运动和存在感。[官方作品页](https://ustwogames.co.uk/our-games/assemble-with-care/)、[官方商店演示](https://store.steampowered.com/app/1202900/Assemble_with_Care/)、[主程序作者技术文章](https://medium.com/@ustwogames/technical-art-in-assemble-with-care-9b31792add10)

**对本作的判断。** “能辨认合适的零件”只是修理的入口。触感来自拿起、定位、受阻、进入、固定、试用的连续关系。当前三选一结束得太早，省掉的恰好是最值得把玩的部分。

**可做的改变。** 保留三件与两项判据，但让所选扣件从托盘来到扣座上方。宽孔件靠上后两端孔各偏出去一点；圆口件两孔对齐却在底部凸榫处翘起。正确件落平，再由玩家合上针。失败成为可理解的物理现象，不只是一句解释。无需增加谜题难度。

### 2. Gorogoa：拼对不是终点，画面会继续发生

**核实事实。** 官方说明玩法是排列、组合图格。Launch Trailer 的连续帧中，树枝与果实所在画格和蓝碗画格被调整视野、重新摆放；两者跨格形成上下关系，鸟离开枝头，果实随后落进碗里。作者 GDC 幻灯片第 30、34、49、55 页讨论图格真实连接、世界中的隐藏潜力、谜题元素在世界中的理由，以及后期拼接后还需推理。[官方商店演示](https://store.steampowered.com/app/557600/Gorogoa/)、[Jason Roberts：The Design of a Cosmic Acrostic](https://media.gdcvault.com/gdc2018/presentations/Roberts_Jason_Gorogoa_design_of.pdf)

**对本作的判断。** 车票已经拥有值得保留的图形依据；缺的是“这几张纸为什么偏偏画成一条长椅”的回报。当前两条线对齐后只出现完成文字，世界未响应线的连通。

**可做的改变。** 接上最后一缝后，不急着显示按钮：月光沿接好的细线走过三张票，滑到长椅扶手；微小的银片随椅背线浮现。玩家点它，纸面银光与场景扶手上银光用同一轨迹接续。只做一次尺度转换就足以赋予图案发现感，不必复制四格结构。

### 3. Samorost 3：环境有回应，人物才像在场

**核实事实。** 官方以魔笛、探索、奇异生物及发现为核心。在 Release Date Trailer 约 57–64 秒的森林段落，小小白色人物与树洞中的长鼻生物同框，生物的鼻尖朝人物下探，再回卷上扬；角色的相对尺度、注视方向和鼻子的动作传达了一次遭遇。本轮抽帧能确认表演变化，不能确认该段的具体点击触发规则，也未试听魔笛。[Amanita 官方页与预告入口](https://amanita-design.net/games/samorost3.html)、[官方商店演示](https://store.steampowered.com/app/421120/Samorost_3/)

**对本作的判断。** 本作的狐与犬画得认真，但在核心操作发生时往往被模糊背景和纸色弹窗遮开；“一人托住、一人合拢”的关系留在文字里。精美不等于人人不断眨眼，而是有一个角色确切看到另一方刚做的事。

**可做的改变。** 只做修扣件近景里的四个反应：小狗先托稳胸针；错误件碰到时爪尖稍让开；狐狸换件时看一眼小狗；合拢后两人先看扣件、再短暂看彼此。每个反应都有触发原因。环境小生物可以晚做。

## 一个约 48 秒的目标片段：把最小的一件东西装好

以下是新分镜建议，不是已实现结果；时长包含一个错误尝试，实际仍由玩家控制，不设失败倒计时。

| 时间 | 画面与玩家动作 | 因果、触感与人物 |
|---|---|---|
| 0–5 秒 | 首饰街全景。狐狸把掌心的胸针放到修理布上，小狗把灯移近。玩家点胸针 | 胸针必须作为独立前景层真实存在；它落在布上后留下同位置阴影。灯先改变它的高光，才有进入近景的理由 |
| 5–9 秒 | 镜头沿胸针位置靠近，桌沿与托盘保留在画面边缘；狐狸指尖轻触月牙上端 | 无纸色任务框接管视野。同一个轮廓和划痕从远景扩大到近景，比例与落点可追踪 |
| 9–16 秒 | 玩家拖动边缘或点击“翻看”，胸针绕接触点抬起，短暂显出银色厚度，再落到背面 | 可以来回把玩。拖动决定进度；点击和键盘播放同一完整动作。投影先拉开再贴回，背面空扣座才被自然发现 |
| 16–24 秒 | 玩家试圆口扣。扣件从托盘来到扣座，两孔对齐，底部却翘起；松手后回到布上 | 一次轻碰与回落，替代红叉。小狗爪尖稳住月牙，狐狸的指尖停一下。必要时才补一句“底下还差一点” |
| 24–32 秒 | 玩家换旧银扣并对准；接近时可吸附，扣件降下去，阴影逐渐收紧 | 三件形状、大小保持一致尺度。孔距和方榫先发生几何对齐，后出现“合适”的结论。容差宽，不测试精细手指控制 |
| 32–38 秒 | 针还开着。玩家压下针尾，前半程顺滑，最后短行程稍慢，越过卡口后轻微回弹 | 一声短促金属接触与锁定同帧发生。此时才记为修复完成；不在选择正确零件时提前发“咔哒” |
| 38–44 秒 | 小狗轻轻提起胸针试一下，扣件不脱落；狐狸松开手，目光落到小狗爪上 | 功能恢复通过试用证明。两人动作先后有配合；不要用成段文案复述刚刚看到的动作 |
| 44–48 秒 | 胸针放回同一块布，镜头退回两人之间。停半秒，才出现“回去吧” | 成功留下位置、朝向与修好状态。允许再次拿起确认，不用全屏成功卡中断余韵 |

**制作最小范围。** 一张清理过的桌面底图、胸针正/背/侧缘、针与扣座分层、三件扣件、两只爪子的关键姿态、可变接触阴影；角色面部只补两次视线变化。用 SVG/分层位图、少量遮罩与时间线已经能验证主张；如果使用 3D，收益应体现为厚度、遮挡和可逆旋转，而不是仅把平面图搬到新引擎。金属与布料音效需人实际试听。

## 按回报与制作成本排序

成本是相对估计，不是工期承诺。先做一段，再决定是否铺开。

| 顺序 | 投入 | 回报 / 成本 | 验收方式 |
|---|---|---|---|
| 1 | 保留胸针 DOM/图层，连续翻面、扣件靠近/受阻/落位、针合拢；把正确音效放到正确动作节点 | 极高 / 中 | 隐藏说明文字，旁观者仍能指出“哪里坏、为什么不合、何时修好”；反复翻面不换位置、不跳比例 |
| 2 | 在原桌面中接近物件，并用同一胸针缩放/转场回原位 | 极高 / 中 | 看 3 秒进入近景录像仍能跟住那枚胸针；主任务不依赖悬空星号说明入口 |
| 3 | 车票最后一缝引出银光；回声抵达引出接收方一次姿态反应 | 高 / 低至中 | 完成时先看到世界变化再读文案；记录观众是否注意到银光去处和谁在回应谁 |
| 4 | 修理段两只爪子、目光与停顿的响应动作 | 高 / 中至高 | 两人的配合即使无对白仍可辨认；不存在不分状态循环的随机眨眼来代替反应 |
| 5 | 把一个可选细节搬回画中，补一个可重复的小行为 | 中 / 中 | 无任务时，观众能因形状/声响/运动主动点到，而不是仅点击右侧目录 |
| 6 | 所有场景全动画、自由行走、大量新谜题或整套引擎迁移 | 未证明 / 高 | 等以上 48 秒通过后再立项；若没有新增可感知行为，技术投入尚未转成表现收益 |

一次截图能证明构图、色彩、材质与排版；精美的交互作品还需要证明两张截图之间的每一步。当前缺少的正是这段证据。最合适的下一次验收材料是“无说明字幕、含一次错误尝试的 48 秒实机动作”，而不是更多封面图或通关测试数量。
