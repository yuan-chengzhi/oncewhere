# 从经历到作品

这是基于[原始备忘录](思考备忘录｜把共同经历变成可探索的作品.md)整理的工作方法建议，尚未经过本项目的完整作品验证。流程可以按作品规模缩短；当前先做第 1–3 步，是否进入实现由后续任务与证据决定。

## 1. 从一个真实的人开始

先找具体当事人与真实用途。下文以赠礼为例，也可按自留、共同讲述等用途调整角色。了解最近发生的事，再介绍形式，避免先展示特效让对方顺着技术想故事。

初次谈话先围绕这些问题展开：

- 你为什么想在这个时候送出这件东西？如果什么都不做，会觉得缺了什么？
- 你最常想起哪个具体片段？当时发生了什么，有什么可以确认的素材？
- 哪个小细节别人不一定懂，但对方会认出来？它对你意味着什么？
- 你已经考虑过信、相册、视频或实物吗？各自哪里合适，哪里不够？
- 对方通常喜欢怎样接收这类表达，会在什么地方、用什么设备打开？
- 哪些内容不适合使用或分享？希望留下什么，交给谁保管？

记录事实、赠送者解释和创作者推论，分别标注。赠送者对接收者感受的描述仍是一个视角。惊喜赠礼可以先向赠送者核实；涉及他人经历或素材时，沿用相关人已确认的使用范围。

**产出：** 一段经历摘要、少量关键细节、素材来源代号与未知项。原始访谈和私人素材保留在 `private/` 或独立存储中。

## 2. 找到作品的工作焦点

使用[作品简报](../templates/work-brief.md)，先说清“为什么现在为这些人做”和“主要想留住什么”。工作焦点可以是一种气氛、一组有张力的感受或一个问题，不必只有一个主旨。选出有依据的细节，说明它们为什么不可随便替换。

同时写下主动舍弃的内容。完整复原整次旅行、收录所有照片或让每个人物都出场，未必有助于这一次表达。

如果核心仍然只能写成“好看、感动、纪念”，先回到经历继续理解。缺少事实就留待确认，不用生成内容把空缺填满。

**产出：** 工作焦点、支持它的细节与本件作品的边界；允许保留不同读法。

## 3. 先比较表达，再选技术

为同一个核心先考虑一个简单载体；若考虑参与动作，再说明它增加的表达价值。例如，可以比较直接读一封信，与依次拿起几件真实纪念物后展开信件。比较的是表达的准确性和接收者负担，不是特效数量；无须交互的作品也可以成立。

用纸面顺序、文字脚本或静态分镜说清：

1. 打开时看见什么，为什么愿意继续。
2. 接收者做一个什么动作，动作怎样对应经历。
3. 哪个细节被发现，核心意义在哪里抵达。
4. 最后在哪里停留，如何回看或留下。

如果必须由作者在旁边补充解释才能成立，优先修正内容与顺序。允许直接阅读、跳过动作和安静结束。

**产出：** 一个最小片段方案与选择理由。这时才查[技术库](互动纪念作品技术库_v0.1.md)中有关的卡片；库中的“默认优先”和实验顺序不替代本件作品的判断。

## 4. 在进入制作前消除关键未知

不必把所有细节研究完，但以下内容要足以指导工作：

| 要说清的事 | 最小结果 |
|---|---|
| 谁在为什么表达 | 具体赠送者、接收者、时刻与一段真实经历 |
| 作品主要关注什么 | 清楚的工作焦点与有来源的细节，允许复杂感受和开放问题 |
| 为什么采用这种体验 | 关键动作的叙事理由；与简单载体的比较 |
| 做到哪里即可 | 一个完整片段、结束位置与暂不加入的内容 |
| 如何被打开和留下 | 实际观看情境、使用范围、交付方式与易观看备份 |

若核心仍然依赖未经确认的记忆、对方不适合这种形式，或交互没有表达作用，就修改简报或缩小作品。技术难点可用独立小样验证，但小样通过不代表作品价值成立。

## 5. 后续制作只完成一个完整片段

先让静态画面和正文成立，再完成关键动作，最后补充确有作用的声音与氛围。技术、资产和设备验收可沿用技术库对应条目。

不要以场景数量、交互数量或模型数量作为完成标准。接收者能顺利进入、理解核心细节、停留阅读和保留作品，才是这个片段要完成的事情。

## 6. 回访这一次表达发生了什么

使用[体验回访](../templates/experience-review.md)。先观察，再问开放问题，例如“你最先注意到什么”“哪一处让你想到那段经历”“有没有让你困惑或不舒服的地方”“你想怎样留着它”。

把“画面好看”“故事属于自己”“操作合适”“愿意留下”分开记录。完成全部操作不等于感到被理解，礼貌称赞也不等于有购买意愿。

需要比较时，让参与者自愿看看同一内容的简单阅读形式，记录其偏好与理由。熟人、赠礼关系和观看顺序都会影响反馈；这是一轮定性学习，不做统计结论。

若对方愿意，在之后一个合适时间问一次是否再次打开或希望保存；未获得反馈就标为未知。保留“删掉交互”“换一种载体”“这件作品不继续”的结论选项。

**产出：** 实际观察、接收者原话、作者解释、与原假设的偏差，以及下一步。第二件作品出现相同制作需要后，再讨论复用什么。
