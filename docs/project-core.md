# 项目核心与需求假设

日期：2026-09-06。依据：[原始思考备忘录](思考备忘录｜把共同经历变成可探索的作品.md)。

本文区分三种内容：**原始立场**是备忘录明确提出的方向；**工作推论**是对方向的解释；**待验证假设**需要真实经历、制作和接收反馈来支持。当前仓库尚未收录访谈记录、已交付作品或付费证据。

## 1. 为什么这件事可能被需要

**原始立场：** 把一个人的故事、一次旅行或一段共同经历做成作品，让接收者亲自经历一次表达。个性化深入到结构，而不仅是替换素材。

**工作推论：** 这里可能存在三种相连的需要：

- **表达：** 赠送者记得许多事，却还没有找到能准确传达心意的方式。
- **被理解：** 接收者通过具体细节，感受到对方确实记得这段经历、理解它的重要性。
- **留存：** 一次送礼之后，作品仍能被重新打开，成为这段关系留下的东西。

照片、信件、视频、相册和实物礼物都可能很好地完成这些任务。oncewhere 的机会在于：对某些经历，参与动作本身也能承载意义，例如寻找对应当年的寻找、拼合对应共同完成、收拾对应告别。是否真的有增益，必须逐件判断。

需求不是“想要一个互动网站”。更接近这样一句尚待验证的话：

> 我想在一个重要时刻，把这段经历为什么对我重要，准确地传达给其中的某个人，并留下一件我们以后还能回看的东西。

## 2. 谁可能需要，什么时候需要

以下是探索入口，不是已经验证的目标市场。日期和节日本身不足以证明需求，还要问“为什么偏偏是这段经历”。

| 可能场景 | 赠送者希望完成什么 | 接收者可能在意什么 | 首先验证 |
|---|---|---|---|
| 一次旅行之后 | 把共同经历里最重要的片段送回给同行者 | 那些只有同行者理解的细节是否被准确记住 | 真正重要的是路线、某个时刻，还是一起度过它的人 |
| 毕业或离别 | 为共同生活的一段时间留下表达 | 是否认出自己的位置和与他人的联系 | 群体叙事会不会遗漏或替人定义感受 |
| 一段关系的重要时刻 | 表达平时难以说清的感谢或珍惜 | 表达是否贴合关系、观看是否自在 | 接收者是否愿意接受这种表达方式 |

赠送者、接收者、制作人是三个角色，可能由同一个人兼任，但评价不能混在一起。制作人觉得效果精彩，不能代替接收者觉得内容与自己有关；赠送者愿意付费，也不能代替接收者愿意保留。

## 3. 项目持续积累什么

**原始立场：** 故事访谈、细节筛选、叙事策划和沟通都是核心工作；先完成一件作品，再考虑平台与商业模式。

**工作推论：** 项目应逐步积累“经历 → 意义 → 体验 → 交付”的判断能力。

| 环节 | 关键判断 | 应留下的材料 |
|---|---|---|
| 理解经历 | 哪个细节重要，谁这样理解，依据是什么 | 经确认的故事摘要与来源代号 |
| 提炼意义 | 赠送者真正想让对方感受到什么 | 一句作品核心与主动舍弃的内容 |
| 组织体验 | 为什么接收者要做这个动作 | 关键片段分镜与简单替代方案 |
| 制作交付 | 什么载体适合对方打开和保留 | 最小实现、交付约定与观看备份 |
| 回看结果 | 对方实际感受到什么，原判断哪里错了 | 区分观察、原话和解释的回访记录 |

可以复用素材整理、状态控制、阅读层、声音开关和归档方法。是否需要公共组件，等第二次真实制作需求出现后再决定。每件作品的意义与叙事结构仍需重新判断。

## 4. 一件作品究竟围绕什么

作品核心要同时落到**具体的人、真实经历、重要细节与想表达的意义**上。可以先用这个句式草拟，再改成自然语言：

> 我想把［经历中的具体细节］做成一件送给［接收者］的作品，因为它对我意味着［核心感受］；希望对方在［关键片段］感受到这一点。

“让对方感动”“记录一次旅行”“做一个可探索房间”都还不够：它们分别缺少具体意义、取舍或形式依据。作品可以表达珍惜，也可以表达幽默、轻松、感谢；不必把所有经历都包装成煽情故事。

判断核心是否找对，可以做三个思想实验：

1. **换人：** 换掉名字和照片，结构是否依然通用？若是，继续寻找改变结构的专属细节。
2. **删效果：** 去掉音乐、粒子和空间特效，表达是否仍然成立？若否，检查故事选择与组织。
3. **换载体：** 用一封信或几张照片能否同样准确地表达？若能，简单形式本身就可能是合适作品；若不能，说清交互补充了什么。

这三个问题帮助取舍，不是机械评分。熟悉的信件结构也可以承载独特表达，独特也不意味着每次都要发明新技术。

## 5. 目前最需要验证什么

| 假设 | 什么观察会支持它 | 什么观察会让我们修改判断 |
|---|---|---|
| H1：存在尚未被合适表达方式满足的真实心意 | 赠送者能描述最近的具体情境、已有尝试及其不足 | 只有听完项目介绍后的泛泛赞同，找不到真实情境 |
| H2：选出的细节能使接收者感到被记得 | 接收者主动认出细节，并说出与其经历有关的意义 | 只赞美画面，关键细节认错或需要作者解释 |
| H3：某个参与动作能加强这次表达 | 接收者能理解动作与故事的联系，动作带来合适节奏 | 觉得操作费力、尴尬，或直接阅读更合适 |
| H4：作品值得被留下 | 对方主动提出保存、再打开或适合自己的留存方式 | 只在当下礼貌观看；之后没有证据，暂不下结论 |
| H5：这种价值能够重复交付 | 多件真实作品中，制作时间、返工和接收反馈可被记录比较 | 每件都必须失控地扩张，或复用使故事变得雷同 |
| H6：有人愿意为完整制作服务付费 | 后续出现真实委托和明确约定 | 仅有“应该有人买”的猜测或口头称赞 |

首件作品先关注 H1–H4。单个案例可以帮助判断一次表达是否成立，不能证明市场规模、稳定复购或普遍付费意愿。回访是自愿的，不用强迫再打开来制造“留存”。

## 6. 适用边界

只有当真实经历和表达意愿足够具体时，这个项目才有合适的起点。接收者不愿探索、关系不适合强烈表达，或者一封信已经充分时，都可以缩小形式或停止制作。

作品不能预先保证感动，也不能替双方解决关系中的分歧。创作者能够负责的是内容准确、表达合适、体验完整，以及尊重当事人自己的解释。
