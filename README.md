# oncewhere

围绕真实经历与关系，探索值得被理解、体验和留下的表达。

> 因为我们有过这段经历，它才会存在。

**当前阶段：首件作品制作与打磨。** [《月背拾遗司》第一夜](works/moon-office/README.md)已有可完整体验的制作初版，包含插画场景、物件谜题、原创钢琴音序与独立 HTML 收藏版。真实观众反馈和最终审美验收仍待进行；本作技术选择不预设为所有后续作品的统一栈。

**方向保持开放。** “为一段具体经历，制作短小、细腻、可以探索和保存的互动作品”是一个候选倾向。媒介、长度、互动程度、情绪和交付对象都可以变化。更值得逐渐形成的是一种别人可以辨认的创作方式：我们怎样观察细节、取舍材料、组织体验，以及让作品在之后的生活里有位置。

## 为什么做

有时，我们想送出的不只是照片或一句祝福，而是让某个人知道：那段一起经历的事情，我记得；其中只有我们理解的细节，对我很重要。

oncewhere 从这种心意出发，探索怎样让一段经历被准确地接近。寻找一件物品、翻开一封信、听见另一个人的讲述、把一个瞬间留在桌上，都可能合适。赠礼是起点之一，也可以继续研究自留、共同讲述或其他用途。

这是一项值得验证的创作主张。哪些人真的需要它、交互是否比一封信或一本相册更合适、能否持续制作和收费，目前都没有结论。

## 项目的核心，与每件作品的核心

**项目的核心**是找到一种可靠的创作方法：理解真实经历，找出对当事人重要的意义，把意义转成恰当的体验，并让作品能够被交付和留下。

**每件作品的核心**是这段关系和经历里值得保留的东西。它可以是一句话、一种默契、气氛、变化或尚未解决的问题，帮助决定保留哪些细节、观众如何接近、最终停在哪里。赠礼作品还要回答“我为什么要把它送给你”。

例如，备忘录中的“总在迷路的旅行”可以启发一张地图，但地图本身还不是作品核心。只有当事人确实认同某种意义——例如“最想记住的是我们一起走错的路”——寻找与绕路才有叙事理由。这只是策划示例，不是已经采集到的真实故事。

一个有用的检查：换一段经历之后，哪些关键选材、线索、措辞、次序或动作必须变化？共享结构与模板可以成为创作语言，不以“结构是否全新”判断表达是否私人。

## 现在做什么

当前围绕《月背拾遗司》的可玩初版继续打磨画面、角色表演、操作反馈与音乐听感。首轮已选择单人柜中小剧场，支持桌面与手机，并提供可独立保管的文件。角色和饰品是否对应私人经历、主要给谁看仍未明确；作品暂按独立可理解的幻想故事制作。

对于源自真实经历的作品，仍先明确具体当事人和可使用的材料，完成作品简报。允许原声、纸本、物件与互动方案被同等考虑，再决定是否值得进入制作。

后续的判断顺序是：真实经历 → 重要细节与可能读法 → 工作焦点 → 如何接近与留下 → 合适载体 → 技术选择。每件作品可以有不同结果。

首件作品成立后，记录对方是否认出专属细节、是否愿意探索、是否愿意保留；再观察哪些制作能力出现了真实的复用需求。平台、模板市场和商业模式留待这些证据出现后讨论。

## 工作原则

- 经历影响关键创作选择，工作焦点帮助取舍，允许作品保留复杂感受与开放问题。
- 交互应参与叙事；简单载体已经表达充分时，就保留简单载体。
- 允许艺术化呈现，真实事件、人物原话和共同记忆以来源为准。
- 复用制作能力与有价值的表达结构；故事、细节和叙事判断逐件完成。
- 收藏从一开始就考虑：正文、图像或视频等易观看备份与交付方式一起设计。

项目起点来自原始备忘录，当前方向结合后续讨论保持开放。产品地图注明本轮官方来源；需求解释、创作建议与验证方法不能当成用户研究结论。技术库按原版本保存，本轮产品研究没有重新核验库内技术版本。
