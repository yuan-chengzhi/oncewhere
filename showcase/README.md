# oncewhere · 作品展示包

解压后，用桌面浏览器打开 `index.html`：先看作品介绍与真实截图，再点击“进入第一夜”。也可以直接打开 `moon-office.html`，无需开发环境、账号或服务器。手机系统的文件预览器未必支持完整交互，线上部署版更适合手机访问。

`moon-office.html` 是完整互动收藏版；作品结尾导出的静态值班记录是另一份文件。`web/` 保留普通静态网站版本，可由作者在确认分享范围后部署；不要把 GitHub 源文件页面当成游戏预览地址。

本包是既有作品的展示整理，不是新的作品版本或观众验收结果。已做哪些测试以对应构建记录为准，不能将自动化浏览器检查解释为真实手机、跨浏览器或人工听感验收。

原作品与项目范围说明见 `CREDITS.md`。`MANIFEST.json` 记录构建提交与哈希，不包含账号凭证。包内不包含 Git 历史、私人访谈、未整理的故事或 Godot 原生样段。
